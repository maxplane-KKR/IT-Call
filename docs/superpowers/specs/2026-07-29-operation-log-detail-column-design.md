# Operation Log Detail Column

## เป้าหมาย

เพิ่มข้อมูล `detail` ลงในรายการเหตุการณ์ เพื่อให้ทีม IT เข้าใจเหตุการณ์ได้จากตารางเดียวโดยไม่ลดความเร็วในการกวาดสายตา

## ทิศทางภาพ

- คงระบบสีและตัวอักษรเดิมทั้งหมด: พื้นน้ำเงินเข้ม, ตัวอักษรหลักสีขาวอมฟ้า, ข้อมูลรองสี muted และแท็กประเภทเหตุการณ์สีเขียว/ฟ้า
- ลายเซ็นของส่วนนี้ยังเป็น “operational density”: ข้อมูลจำนวนมาก อ่านเป็นแถวได้เร็ว และไม่มีการ์ดหรือสีใหม่ที่แย่งความสนใจ
- ใช้ข้อความรายละเอียดเป็นข้อมูลรอง ไม่เพิ่มปุ่มหรือ interaction ใหม่

## Desktop

เพิ่มคอลัมน์ `รายละเอียด` ระหว่าง `แผนก` และ `เหตุการณ์`

```text
| วันเวลา | ผู้ปฏิบัติงาน | แผนก | รายละเอียด               | เหตุการณ์ |
|---------|----------------|------|---------------------------|-----------|
| 29/07  | กรพีรวัศ       | ER   | ตรวจสอบสิทธิ์ VPN ผู้ใช้… | ทั่วไป    |
```

- คอลัมน์รายละเอียดเป็นคอลัมน์ยืดหยุ่นและกว้างที่สุด
- จำกัดข้อความที่ 2 บรรทัดเพื่อคงความสูงของแถว
- เก็บข้อความเต็มไว้ใน DOM และใส่ `title` เพื่อให้ผู้ใช้เดสก์ท็อปอ่านเต็มเมื่อชี้เมาส์
- รายการที่ไม่มีรายละเอียดแสดง `—`
- เพิ่มความกว้างขั้นต่ำของตารางเพื่อไม่ให้คอลัมน์อื่นถูกบีบ; container เดิมยังเลื่อนแนวนอนได้เมื่อจอแคบ

## Mobile

วางรายละเอียดเป็นบล็อกข้อความเต็มระหว่างข้อมูลผู้ปฏิบัติงาน/แผนกกับแท็กเหตุการณ์

```text
29/07 · 20:15
กรพีรวัศ                     ER

รายละเอียด
ตรวจสอบสิทธิ์ VPN ผู้ใช้งาน
──────────────────────────────
[ทั่วไป]
```

- แสดงข้อความเต็มและตัดคำยาวได้ เพื่อให้ผู้ใช้จอสัมผัสไม่ต้องพึ่ง hover
- รายการที่ไม่มีรายละเอียดแสดง `—`

## ข้อมูลและพฤติกรรม

- ใช้ `record.detail` ที่ API และ normalization มีอยู่แล้ว ไม่เพิ่มคำขอ API
- การกรอง, pagination, CSV และการคำนวณทั้งหมดคงเดิม
- ไม่เปลี่ยน light/dark mode, PWA, Apps Script หรือกลไก cache

## การตรวจสอบ

- เพิ่ม regression test ว่า desktop มีหัวคอลัมน์ `รายละเอียด` และ render `record.detail`
- เพิ่ม regression test ว่า mobile card render `record.detail`
- ตรวจกรณีรายละเอียดว่างให้แสดง `—`
- ตรวจ UI จริงที่ viewport 390×844 (iOS) และ 360×800 (Android)
- ยืนยันว่าไม่มี horizontal overflow, รายละเอียดยาวตัดคำได้, ความสูงการ์ดอ่านง่าย และแท็กเหตุการณ์ไม่ชนข้อความ
- รัน build, test suite และ lint ทั้งหมดก่อนบันทึก Sites เวอร์ชันใหม่
