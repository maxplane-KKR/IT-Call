# สเป็กการรวมสรุป HR เข้าหน้า Dashboard บน iPad

วันที่: 12 สิงหาคม 2569

## เป้าหมาย

ปรับหน้า iPad Air ให้ใช้พื้นที่จอจริงโดยไม่มีพื้นที่ว่างยาวด้านล่าง และย้ายเนื้อหา “สรุป HR” จากแท็บแยกมาอยู่ในหน้า Dashboard โดยยังคงข้อมูล การส่งออก CSV และความสามารถเดิมครบถ้วน

## โครงหน้า

### iPad แนวตั้ง 768–1023 พิกเซล

เรียงเนื้อหาเป็น 3 ส่วนจากบนลงล่าง:

1. การ์ดตัวเลขสรุป 4 ใบในแถวเดียว
2. การ์ดกราฟแนวโน้มที่ขยายตามพื้นที่คงเหลือ
3. การ์ดสรุป HR ที่ขยายตามพื้นที่คงเหลือ

หน้า Dashboard มีความสูงอย่างน้อยเท่าพื้นที่จอ และให้หน้าหลักเลื่อนตามเนื้อหาโดยไม่มี scroll container ซ้อนอยู่ในการ์ด HR

### iPad แนวนอน 1024–1279 พิกเซล

วาง 3 ส่วนเป็น 3 คอลัมน์ ได้แก่ ตัวเลขสรุป กราฟแนวโน้ม และสรุป HR เพื่อใช้พื้นที่แนวนอนให้เต็ม โดยให้หน้าหลักเลื่อนเมื่อเนื้อหายาวกว่าจอ

### หน้าจออื่น

- มือถือขนาดต่ำกว่า 768 พิกเซลเรียงตัวเลขสรุป กราฟ และ HR ต่อกันใน Dashboard และให้หน้าเลื่อนตามเนื้อหาตามปกติ
- เดสก์ท็อปตั้งแต่ 1280 พิกเซลขึ้นไปไม่เปลี่ยนโครงเดิม

## แถบนำทาง

ตัดเมนู “สรุป HR” ออกจากแถบนำทางด้านล่าง เหลือ 3 เมนูตามลำดับ:

1. Dashboard
2. รายการ Log
3. กราฟสถิติ

สถานะ active, keyboard navigation และ swipe ใช้รายการเมนูที่เหลือโดยไม่อ้างตำแหน่งคงที่

## ข้อมูลและพฤติกรรม

- ใช้ `mobileHRContainer` และ `mobileHRSubtitle` เดิม เพื่อไม่ทำซ้ำ logic การคำนวณหรือ render
- ปุ่มดาวน์โหลด CSV ของ HR ยังคงอยู่ในการ์ด HR
- การเปลี่ยนตัวกรองเดือนต้องอัปเดตสรุป HR และกราฟเหมือนเดิม
- ไม่เพิ่ม dependency และไม่แก้ API, สูตรคำนวณ หรือข้อมูลต้นทาง

## การรองรับการเข้าถึง

- ปุ่มนำทางที่เหลือคง `role="tab"`, `aria-selected`, `aria-controls` และลำดับโฟกัสเดิม
- รายการ HR แสดงต่อเนื่องทั้งหมด และใช้การเลื่อนของหน้าหลักที่รองรับ touch
- ไม่ซ่อนข้อมูลสำคัญด้วยการตัดข้อความถาวร

## การทดสอบรับรองผล

- ตรวจว่าไม่มีปุ่ม `data-tab="hr"` ในแถบนำทาง
- ตรวจว่า `mobileHRContainer` อยู่ภายใน `mobile-section-dashboard`
- ตรวจ iPad แนวตั้งว่ามี 3 แถว การ์ด HR ไม่เลื่อนภายใน และหน้าหลักเลื่อนได้
- ตรวจ iPad แนวนอนว่ามี 3 คอลัมน์
- รัน regression tests ทั้งหมดและ lint

## นอกขอบเขต

- ไม่เปลี่ยนหน้าตาเดสก์ท็อป
- ไม่ปรับสูตรค่าตอบแทนหรือ API
- ไม่ deploy ขึ้น production จนกว่าจะได้รับอนุญาตโดยตรง
